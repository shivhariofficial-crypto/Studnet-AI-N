# EduBot AI - Smart Student AI Study Assistant 🎓⚡

A modern, responsive, real-time AI-powered Student Study Tutor & Academic Assistant built with Google Gemini API, featuring student onboarding, concept breakdowns, step-by-step problem solvers, quizzes, and session history management.

---

## 🌟 Key Features

- **🚀 Live Google Gemini AI Integration**: Fast, real-time responses powered by Google's latest Gemini models (`gemini-3.7-flash`, `gemini-3.6-flash`, `gemini-3.5-flash`).
- **👤 Student Academic Portal (Onboarding)**:
  - Student Name, School / Institute Name, Class / Standard, and Roll Number input.
  - Quick-select pills for classes (9th, 10th, 11th PCM, 12th PCB, Commerce, College).
  - Dynamic AI personalization tailored to the student's grade level and curriculum.
- **📚 Smart Academic Tools**:
  - **Explain Concept**: Simple explanations with intuitive analogies.
  - **Summarize Notes**: Bullet points, key formulas, and memory mnemonics.
  - **Practice Quizzes**: Multiple-choice questions with answer keys & explanations.
  - **Step-by-Step Solver**: Complete calculation breakdowns for homework & math.
- **💬 Chat Session & History Management**:
  - Auto-saved conversation sessions in local storage.
  - Sidebar past chat history with instant resume and deletion.
- **🎨 Glassmorphic & Responsive Design**:
  - Tailored Dark / Light themes with smooth transitions.
  - Mobile responsive drawer and clean typography.
  - Lucide icons & markdown rendering with syntax highlighting.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS3**: Custom design system, CSS variables, glassmorphism, responsive grid & flexbox layouts.
- **JavaScript (ES6+)**: Real-time Google Generative Language API integration, local state management, markdown parser.
- **Google Generative AI**: Gemini Flash models for real-time tutoring.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/shivhariofficial-crypto/Studnet-AI-N.git
cd Studnet-AI-N
```

### 2. Run locally
You can open `index.html` directly in your browser or run a simple local web server:

```bash
# Using Python
python3 -m http.server 3000

# Using Node.js
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🔑 Gemini API Configuration

You can enter your Google Gemini API key directly in the sidebar settings or get a free API key from [Google AI Studio](https://aistudio.google.com/app/apikey).
